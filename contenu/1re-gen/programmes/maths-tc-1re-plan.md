# Plan des chapitres : mathématiques du tronc commun, première générale

Plan déduit du programme résumé dans `maths-tc-1re.md` : arrêté du 26 février 2026 (NOR MENE2602916A, BO n° 14 du 2 avril 2026), applicable à la rentrée 2026-2027, et note de service MENE2622640N sur l'épreuve anticipée. Codes `[Au…]`, `[N…]`, `[C…]` définis dans `maths-tc-1re.md`.

**Statut** : proposition, à valider par l'enseignant (voir « Points à trancher »).

## Principes du découpage

- Un chapitre par modèle ou par grande notion du programme ; l'ordre reste au choix du professeur.
- **Automatismes** : le programme ne veut pas de chapitre spécifique, mais l'épreuve anticipée leur consacre 6 points sur 20, sans calculatrice. L'application a besoin d'une page de référence et d'un entraînement : trois chapitres courts (1 à 3) regroupent les automatismes de calcul, d'évolutions et de lecture graphique ; les automatismes de statistiques et de probabilités sont traités dans les chapitres 4 et 5. Chaque banque contient aussi des questions « flash » de calcul mental. C'est un écart assumé à la lettre du programme, à trancher par l'enseignant.
- **Calculatrice interdite à l'épreuve** : les exemples et les questions utilisent des nombres qui se calculent de tête (1,1² = 1,21 ; 2<sup>10</sup> = 1 024 ; 0,5<sup>3</sup> = 0,125…). Quand un calcul exige un outil (puissance non entière), la valeur est donnée dans l'énoncé.
- Durées indicatives : 32 semaines à 1 h 30.

## Détail des chapitres

### 1. Pourcentages et taux d'évolution
Proportion et pourcentage (partie, tout) ; coefficient multiplicateur CM = 1 + t ; valeur finale et valeur initiale ; taux d'évolution (V<sub>A</sub> − V<sub>D</sub>)/V<sub>D</sub> ; évolutions successives (produit des CM) ; taux réciproque (1/CM − 1) ; pièges (une hausse de 10 % puis une baisse de 10 % ne se compensent pas ; points de pourcentage). Liens : chapitre 9 et 10.

### 2. Calcul algébrique, équations produit nul et signe
Développer, réduire, identités remarquables ; factoriser (facteur commun, identités) ; équation produit nul ; équations du premier degré, x² = a ; signe de ax + b ; tableau de signes d'un produit de deux facteurs du premier degré ; signe de a(x − x<sub>1</sub>)(x − x<sub>2</sub>) ; application numérique d'une formule, isoler une variable.

### 3. Lectures graphiques et droites
Image, antécédent ; résoudre graphiquement f(x) = k, f(x) < k, f(x) ⩾ g(x) ; signe et tableau de variations lus sur une courbe ; équation réduite y = mx + p, coefficient directeur m = (y<sub>B</sub> − y<sub>A</sub>)/(x<sub>B</sub> − x<sub>A</sub>), ordonnée à l'origine ; tracer une droite ; lire l'équation d'une droite ; droites parallèles ; point sur une droite.

### 4. Statistiques à deux caractères
Rappels : lire un diagramme (barres, circulaire, histogramme, boîte), moyenne, médiane, quartiles, étendue, écart interquartile ; tableau croisé d'effectifs, effectifs marginaux, fréquences (globale, marginale, conditionnelle) ; diagrammes du croisement ; nuage de points, point moyen G(x̄ ; ȳ) ; ajustement affine (au jugé, droite de Mayer, moindres carrés au tableur sans théorie) ; interpolation, extrapolation et leurs limites ; corrélation n'est pas causalité ; tableur.

### 5. Probabilités conditionnelles et indépendance
Rappels (univers, événement contraire, équiprobabilité, intersection, réunion) ; probabilité conditionnelle P<sub>A</sub>(B) ; tableau croisé ; arbre pondéré (règles des branches, formule des probabilités totales sur un arbre à deux niveaux) ; distinguer P(A ∩ B), P<sub>A</sub>(B), P<sub>B</sub>(A) ; tests médicaux (faux positifs et faux négatifs) ; indépendance (P<sub>B</sub>(A) = P(A) ⇔ P(A ∩ B) = P(A) × P(B)) ; Monty Hall.

### 6. Répétition d'épreuves indépendantes et simulation
Épreuve de Bernoulli (succès, échec, p) ; répétition de n épreuves identiques et indépendantes, n ⩽ 4 ; arbre ; probabilité d'un chemin (p<sup>k</sup>(1 − p)<sup>n−k</sup>) ; nombre de chemins avec k succès (lus sur l'arbre) ; « au moins un succès » = 1 − (1 − p)<sup>n</sup> ; tirages avec et sans remise ; simulation (Python, tableur), fluctuation, loi des grands nombres ; jeux historiques (croix ou pile, problème des partis).

### 7. Variation linéaire : suites arithmétiques et fonctions affines
Suite, notation u(n) puis u<sub>n</sub>, rang ; suite arithmétique : u(n+1) = u(n) + r, u(n) = u(0) + nr, u(n) = u(1) + (n − 1)r ; sens de variation selon r ; nuage de points alignés ; fonction affine f(x) = mx + p, taux d'accroissement constant = m ; intérêts simples ; Celsius-Fahrenheit ; offre et demande ; fonction affine par morceaux (barème, taux marginal, taux moyen) ; problèmes de seuil.

### 8. Modélisation quadratique
x ↦ ax², x ↦ ax² + c : paraboles, sommet, sens selon le signe de a ; forme factorisée a(x − x<sub>1</sub>)(x − x<sub>2</sub>) : racines, axe x = (x<sub>1</sub> + x<sub>2</sub>)/2, sommet, signe ; f(x) = ax² + bx + c : axe de symétrie en résolvant f(x) = c (x = 0 ou x = −b/a, axe au milieu), sommet, tableau de variations ; maximum, minimum ; modèles (trajectoire, chiffre d'affaires, arche). Pas de discriminant.

### 9. Suites géométriques
Suite géométrique de raison q > 0 : u(n+1) = q × u(n), u(n) = u(0) × q<sup>n</sup> ; lien avec un taux d'évolution constant (q = 1 + t) ; sens de variation (q > 1, q < 1) ; représentation (points non alignés) ; intérêts composés, élimination d'un médicament, demi-vie (nombre entier de demi-vies), Sierpinski, rumeur ; comparaison linéaire / exponentiel ; seuil par calcul de termes successifs ou tableur.

### 10. Fonctions exponentielles et taux moyen
Prolongement de n ↦ q<sup>n</sup> à x ↦ a<sup>x</sup> (a > 0, x ⩾ 0) ; propriétés admises (a<sup>x+y</sup> = a<sup>x</sup> × a<sup>y</sup>, (a<sup>x</sup>)<sup>y</sup> = a<sup>xy</sup>, a<sup>0</sup> = 1) ; a<sup>1/2</sup> = √a, a<sup>1/n</sup> racine n-ième ; variations selon a > 1, a < 1, a = 1 ; courbe passant par (0 ; 1) et (1 ; a) ; taux d'évolution moyen t<sub>M</sub> = (CM)<sup>1/n</sup> − 1 ; capital au bout d'une fraction d'année ; demi-vie fractionnaire ; ordres de grandeur ; seuil.

## Points à trancher

1. Trois chapitres d'automatismes (1 à 3), alors que le programme demande un entraînement régulier sans chapitre spécifique.
2. Recouvrement avec la spécialité (`maths-spe`) et l'enseignement scientifique : même programme d'automatismes, contenus différents ; aucune page commune.
3. Durées (32 semaines à 1 h 30) et ordre : le programme laisse libre ; on peut alterner automatismes et parties thématiques.
