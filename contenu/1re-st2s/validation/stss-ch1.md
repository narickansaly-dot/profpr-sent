## Texte du cours

- a_retenir : corrigé. Ambiguïté : « décrite » pouvait se rapporter à « population » au lieu de « santé collective ». Questions liées (013, 064) inchangées.
- Point 1 (santé collective / santé publique) : rien changé. La distinction état / action est juste et courante en ST2S ; à vérifier seulement avec ton manuel.
- Point 2 (santé globale) : rien changé. Le sens « approche holistique » est celui du programme ; le sens « santé mondiale » n'est pas utilisé, donc pas d'ambiguïté dans le texte.
- Point 3 (préoccupation de santé publique) : rien changé. Définition de travail présentée comme telle, cohérente avec le renvoi au chapitre 6.
- Point 4 (citation de Leriche) : rien changé. Attribution correcte, sans date : rien d'invérifiable n'est affirmé.
- Point 5 (question de santé perçue) : rien changé. Présentée comme un exemple (« souvent »), sans enquête citée ; le vouvoiement est dans la citation, pas adressé à l'élève.
- Point 6 (longueur) : rien changé. Choix éditorial, pas une erreur ; la consigne exclut toute réécriture.
