# Relecture de la banque du chapitre 7 de français (2de) contre le cours

Relecture des 149 questions de `francais-ch7.json` contre le texte du chapitre « Le verbe : temps, aspects, modes et concordance », question par question. Critères : exactitude grammaticale (chaque forme proposée vérifiée), une seule lecture possible, explication qui donne la règle, niveau seconde, variantes des réponses courtes, typographie et tutoiement.

## Points de doute pour l'enseignant

1. **Statut du conditionnel** : le cours présente les deux analyses (mode ou temps de l'indicatif). Aucune question ne demande de trancher ; une question demande seulement pourquoi les grammaires actuelles le rattachent à l'indicatif.
2. **Terminologie de l'aspect** (global / sécant, semelfactif / itératif) : termes exigeants pour une seconde ; ils figurent dans le programme (« valeurs aspectuelles ») mais tu peux préférer « limité / non limité ».
3. **Présent de narration et premier plan** : le qcm_multiple qui le range parmi les temps de premier plan est juste selon le cours, mais il peut surprendre ; vérifie qu'il correspond à ta présentation.
4. **Imparfait du subjonctif** : présenté pour la lecture des textes classiques ; une seule question l'identifie (« vînt »).
5. **Réponses courtes de conjugaison** (« viendrait », « voudrais », « vienne », « était », « lut ») : seule la forme exacte est acceptée.
6. ***L'Étranger*** : l'analyse « récit sans recul, fait de moments juxtaposés » est une interprétation courante du passé composé chez Camus ; c'est une lecture, pas un fait.
