# Étape 2 : quiz, évaluations et tableau de bord élève — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** l'élève passe des quiz de chapitre (15, 20 ou 30 questions tirées au hasard, validés à 75 %), débloque puis passe l'évaluation du cours (40 questions, 60 minutes, 3 essais, 24 heures entre deux essais), et retrouve sa progression, ses notes et ses points faibles sur un tableau de bord.

**Architecture :** tout ce qui touche aux réponses vit dans Postgres. Des fonctions `security definer` exposées en RPC tirent les questions, enregistrent les réponses et corrigent. Les bonnes réponses ne sortent de la base qu'après la clôture d'une tentative. Les helpers internes sont dans un schéma `prive`, que l'API n'expose pas. Les tables de résultats sont lisibles par leur propriétaire via la RLS. Elles ne sont écrites que par ces fonctions. Next.js appelle les RPC depuis des server actions et affiche un lecteur de quiz côté client, qui enregistre chaque réponse au fil de l'eau.

**Tech Stack :** Next.js 16, React 19, TypeScript, Supabase (Postgres 17, plpgsql, extension `unaccent`), zod, Vitest, pgTAP, Playwright.

**Spec :** `docs/superpowers/specs/2026-11-03-app-lycee-design.md`. Sections concernées : 3 « Résultats », 4 « Quiz de chapitre », « Évaluation du cours », « Correction des réponses courtes », « QCM à plusieurs réponses » et 5 « Élève ».
**Bilan de l'étape 1 (points reportés à l'étape 2) :** `docs/superpowers/plans/2026-11-03-etape-1-bilan.md`.

## Contraintes globales

- Toute l'interface est **en français**. Les messages tutoient l'élève, avec des formulations non genrées.
- Seuil de réussite : **75 %** (`note >= 75`). Les notes sont des pourcentages de 0 à 100, avec deux décimales.
- Quiz de chapitre :
  - **15, 20 ou 30** questions, uniquement au statut `valide`. Si le chapitre en a moins que demandé, on prend toutes celles qui sont disponibles.
  - Le quiz est **indisponible sous 15 questions validées**.
  - Ordre de tirage : jamais vues, puis déjà ratées, puis les autres, au hasard dans chaque groupe. Le mode « révision » met les ratées en premier.
  - Nombre d'essais illimité. On garde la meilleure note.
- Évaluation de cours :
  - Débloquée quand **tous les chapitres publiés** du cours sont validés.
  - **40** questions, réparties à peu près à égalité entre les chapitres.
  - **60 minutes**, avec une date limite fixée côté serveur.
  - **3 essais** au maximum, avec **24 heures** d'attente après la fin d'un essai.
  - Réponses enregistrées au fil de l'eau. Une évaluation expirée est corrigée avec les réponses déjà données.
- Correction :
  - QCM : il faut **toutes** les bonnes cases et aucune autre (pas de point partiel).
  - Réponse courte : on ignore les majuscules, les accents, les espaces en trop et la ponctuation finale.
  - Réponse numérique : la virgule et le point sont acceptés, avec une marge absolue ou relative.
- **Les élèves ne lisent jamais `question_corrige`.** La correction ne passe que par `correction_tentative`, et seulement après la clôture.
- Les tables de résultats (`tentative`, `tentative_question`, `progression_chapitre`, `progression_cours`, `historique_question`) sont en **lecture seule pour leur propriétaire**. Aucune écriture directe pour `authenticated`. Aucun accès pour `anon`.
- Chaque fonction exposée a `set search_path = ''` et des noms qualifiés. On applique `revoke execute … from public, anon` puis `grant execute … to authenticated`.
- Les codes d'erreur levés par la base sont des mots-clés en `snake_case` (liste en Task 8). L'application les traduit en français.
- Avant d'écrire du code qui utilise Next.js, `@supabase/ssr`, supabase-js ou plpgsql, consulter leur documentation à jour avec **context7**. Si une API du plan a changé, suivre la documentation et le signaler dans le rapport.
- Commandes shell : préfixer par `export PATH="$HOME/.orbstack/bin:$PATH";` (Docker via OrbStack). Ne jamais afficher ni commiter `.env.local`.
- Après chaque nouvelle migration : `npm run db:reset`, puis régénérer les types avec `npx supabase gen types typescript --local > src/lib/supabase/types.ts`.
- Messages de commit en français, à l'impératif présent, terminés par la ligne `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```ts
import { createClient } from '@supabase/supabase-js';

/** Supprime les comptes créés par les tests (adresse en @test.local). */
export default async function nettoyage() {
  process.loadEnvFile('.env.local');
  const db = createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.SUPABASE_SERVICE_ROLE_KEY!, {
    auth: { persistSession: false },
  });
  for (let page = 1; ; page++) {
    const { data, error } = await db.auth.admin.listUsers({ page, perPage: 200 });
    if (error) throw error;
    const aSupprimer = data.users.filter((u) => u.email?.endsWith('@test.local'));
    for (const u of aSupprimer) await db.auth.admin.deleteUser(u.id);
    if (data.users.length < 200) break;
  }
}
```

```sql
-- Correction des réponses. Schéma prive : non exposé par l'API, appelé par les fonctions de quiz.

create extension if not exists unaccent with schema extensions;

create schema prive;
revoke all on schema prive from public, anon, authenticated;

create function prive.normaliser(p text) returns text
language sql stable set search_path = '' as $$
  select regexp_replace(
           regexp_replace(lower(extensions.unaccent(trim(coalesce(p, '')))), '\s+', ' ', 'g'),
           '[\s.!?;:,]+$', '')
$$;

create function prive.en_nombre(p text) returns numeric
language plpgsql immutable set search_path = '' as $$
begin
  return replace(trim(p), ',', '.')::numeric;
exception when others then
  return null;
end $$;

create function prive.corriger(p_question uuid, p_reponse jsonb) returns boolean
language plpgsql stable set search_path = '' as $$
declare
  q record;
  donne numeric;
  attendu numeric;
begin
  if p_reponse is null or jsonb_typeof(p_reponse) <> 'array' or jsonb_array_length(p_reponse) = 0 then
    return false;
  end if;
  select qu.type, c.bonnes_reponses, c.reponses_acceptees, c.marge, c.marge_relative into q
    from public.question qu join public.question_corrige c on c.question_id = qu.id
    where qu.id = p_question;
  if not found then
    return false;
  end if;

  case q.type
    when 'qcm_unique', 'vrai_faux' then
      return p_reponse = q.bonnes_reponses;
    when 'qcm_multiple' then
      return (select array_agg(distinct v order by v) from jsonb_array_elements_text(p_reponse) v)
           = (select array_agg(distinct v order by v) from jsonb_array_elements_text(q.bonnes_reponses) v);
    when 'reponse_courte' then
      if jsonb_typeof(p_reponse -> 0) <> 'string' then
        return false;
      end if;
      if exists (select 1 from unnest(q.reponses_acceptees) a
                 where prive.normaliser(a) = prive.normaliser(p_reponse ->> 0)) then
        return true;
      end if;
      if q.marge is null then
        return false;
      end if;
      donne := prive.en_nombre(p_reponse ->> 0);
      attendu := prive.en_nombre(q.reponses_acceptees[1]);
      if donne is null or attendu is null then
        return false;
      end if;
      return abs(donne - attendu) <= case when q.marge_relative then q.marge * abs(attendu) else q.marge end;
  end case;
end $$;

create function prive.melanger(n int) returns smallint[]
language sql volatile set search_path = '' as $$
  select coalesce(array_agg(i::smallint order by random()), '{}') from generate_series(0, n - 1) as i
$$;

create function prive.vers_original(p_type public.type_question_t, p_permutation smallint[], p_reponse jsonb)
returns jsonb
language plpgsql immutable set search_path = '' as $$
declare
  n int := coalesce(array_length(p_permutation, 1), 0);
  v jsonb;
  idx int;
  resultat jsonb := '[]';
begin
  if p_reponse is null or p_reponse = '[]'::jsonb then
    return null;
  end if;
  if jsonb_typeof(p_reponse) <> 'array' then
    raise exception 'reponse_invalide';
  end if;
  case p_type
    when 'qcm_unique', 'qcm_multiple' then
      if p_type = 'qcm_unique' and jsonb_array_length(p_reponse) <> 1 then
        raise exception 'reponse_invalide';
      end if;
      for v in select * from jsonb_array_elements(p_reponse) loop
        if jsonb_typeof(v) <> 'number' or v::text !~ '^\d+$' then
          raise exception 'reponse_invalide';
        end if;
        idx := v::text::int;
        if idx >= n or resultat @> jsonb_build_array(p_permutation[idx + 1]) then
          raise exception 'reponse_invalide';
        end if;
        resultat := resultat || jsonb_build_array(p_permutation[idx + 1]);
      end loop;
      return (select jsonb_agg(x order by x::text::int) from jsonb_array_elements(resultat) x);
    when 'vrai_faux' then
      if jsonb_array_length(p_reponse) <> 1 or jsonb_typeof(p_reponse -> 0) <> 'boolean' then
        raise exception 'reponse_invalide';
      end if;
      return p_reponse;
    when 'reponse_courte' then
      if jsonb_array_length(p_reponse) <> 1 or jsonb_typeof(p_reponse -> 0) <> 'string'
         or char_length(trim(p_reponse ->> 0)) not between 1 and 200 then
        raise exception 'reponse_invalide';
      end if;
      return jsonb_build_array(trim(p_reponse ->> 0));
  end case;
end $$;

create function prive.vers_affiche(p_type public.type_question_t, p_permutation smallint[], p_valeur jsonb)
returns jsonb
language sql immutable set search_path = '' as $$
  select case
    when p_valeur is null then null
    when p_type in ('qcm_unique', 'qcm_multiple') then
      (select coalesce(jsonb_agg(a.pos order by a.pos), '[]'::jsonb)
         from (select array_position(p_permutation, (v::text)::smallint) - 1 as pos
                 from jsonb_array_elements(p_valeur) v) a)
    else p_valeur
  end
$$;

create function prive.propositions_affichees(p_propositions jsonb, p_permutation smallint[]) returns jsonb
language sql immutable set search_path = '' as $$
  select coalesce(jsonb_agg(p_propositions -> (u.p)::int order by u.ord), '[]'::jsonb)
  from unnest(p_permutation) with ordinality as u(p, ord)
$$;

revoke execute on all functions in schema prive from public, anon, authenticated;
```

```sql
create function prive.cloturer(p_tentative uuid, p_statut public.statut_tentative_t) returns void
language plpgsql security definer set search_path = '' as $$
declare
  t public.tentative;
  v_note numeric(5,2);
begin
  select * into t from public.tentative where id = p_tentative for update;
  if not found or t.statut <> 'en_cours' then
    return;
  end if;

  update public.tentative_question tq
     set correcte = prive.corriger(tq.question_id, tq.reponse)
   where tq.tentative_id = p_tentative;

  select round(100.0 * count(*) filter (where correcte) / count(*), 2) into v_note
    from public.tentative_question where tentative_id = p_tentative;

  update public.tentative
     set statut = p_statut, fin = now(), note = v_note, reussie = v_note >= 75
   where id = p_tentative;

  insert into public.historique_question as h (eleve_id, question_id, vue, ratee, derniere_reponse)
    select t.eleve_id, tq.question_id, 1, case when tq.correcte then 0 else 1 end, now()
      from public.tentative_question tq where tq.tentative_id = p_tentative
  on conflict (eleve_id, question_id) do update
    set vue = h.vue + 1, ratee = h.ratee + excluded.ratee, derniere_reponse = now();

  if t.type = 'evaluation_cours' then
    insert into public.progression_cours as p (eleve_id, cours_id, meilleure_note, valide, valide_le, essais, dernier_essai)
      values (t.eleve_id, t.cours_id, v_note, v_note >= 75, case when v_note >= 75 then now() end, 1, now())
    on conflict (eleve_id, cours_id) do update set
      meilleure_note = greatest(p.meilleure_note, excluded.meilleure_note),
      valide = p.valide or excluded.valide,
      valide_le = coalesce(p.valide_le, excluded.valide_le),
      essais = p.essais + 1,
      dernier_essai = now();
  else
    insert into public.progression_chapitre as p (eleve_id, chapitre_id, meilleure_note, valide, valide_le)
      values (t.eleve_id, t.chapitre_id, v_note, v_note >= 75, case when v_note >= 75 then now() end)
    on conflict (eleve_id, chapitre_id) do update set
      meilleure_note = greatest(p.meilleure_note, excluded.meilleure_note),
      valide = p.valide or excluded.valide,
      valide_le = coalesce(p.valide_le, excluded.valide_le);
  end if;
end $$;

create function prive.cloturer_si_expiree(p_tentative uuid) returns boolean

begin

             where id = p_tentative and statut = 'en_cours' and date_limite is not null and date_limite < now()) then
    perform prive.cloturer(p_tentative, 'expiree');
    return true;
  end if;
  return false;
end $$;

create function public.demarrer_quiz(p_chapitre uuid, p_nb int, p_revision boolean default false) returns uuid
language plpgsql security definer set search_path = '' as $$
declare
  v_cours uuid;
  v_dispo int;
  v_nb int;
  v_id uuid;
begin
  if auth.uid() is null then
    raise exception 'non_connecte';
  end if;
  if p_nb is null or p_nb not in (15, 20, 30) then
    raise exception 'longueur_invalide';
  end if;
  select c.cours_id into v_cours from public.chapitre c where c.id = p_chapitre and c.publie;
  if v_cours is null or not public.peut_lire_cours(v_cours) then
    raise exception 'acces_refuse';
  end if;
  select count(*) into v_dispo from public.question q where q.chapitre_id = p_chapitre and q.statut = 'valide';
  if v_dispo < 15 then
    raise exception 'quiz_indisponible';
  end if;
  v_nb := least(p_nb, v_dispo);

  insert into public.tentative (eleve_id, type, cours_id, chapitre_id, nb_questions)
    values (auth.uid(), case when p_revision then 'revision' else 'quiz_chapitre' end::public.type_tentative_t,
            v_cours, p_chapitre, v_nb)
    returning id into v_id;

  -- Priorité : jamais vues (0), ratées (1), les autres (2). En révision, les ratées passent devant.
  insert into public.tentative_question (tentative_id, ordre, question_id, permutation)
    select v_id, row_number() over (order by s.priorite, s.alea), s.id, prive.melanger(jsonb_array_length(s.propositions))
      from (
        select q.id, q.propositions, random() as alea,
               case
                 when h.question_id is null then case when p_revision then 1 else 0 end
                 when h.ratee > 0 then case when p_revision then 0 else 1 end
                 else 2
               end as priorite
          from public.question q
          left join public.historique_question h on h.question_id = q.id and h.eleve_id = auth.uid()
         where q.chapitre_id = p_chapitre and q.statut = 'valide'
         order by priorite, alea
         limit v_nb
      ) s;
  return v_id;
end $$;

create function public.questions_tentative(p_tentative uuid)
returns table (ordre smallint, question_id uuid, type public.type_question_t, enonce text, propositions jsonb, reponse jsonb)
language plpgsql security definer set search_path = '' as $$
#variable_conflict use_column
begin

create function public.repondre(p_tentative uuid, p_question uuid, p_reponse jsonb) returns text
language plpgsql security definer set search_path = '' as $$
declare
  v_statut public.statut_tentative_t;
  v_type public.type_question_t;
  v_permutation smallint[];
begin
  select statut into v_statut from public.tentative where id = p_tentative and eleve_id = auth.uid();

    raise exception 'tentative_introuvable';
```

```sql
create function public.demarrer_evaluation(p_cours uuid) returns uuid
language plpgsql security definer set search_path = '' as $$
declare
  v_id uuid;
  v_nb_chapitres int;
  v_nb_valides int;
  v_essais int;
  v_derniere_fin timestamptz;
  v_dispo int;
  r record;
begin
  if auth.uid() is null then
    raise exception 'non_connecte';
  end if;
  if not public.peut_lire_cours(p_cours) then
    raise exception 'acces_refuse';
  end if;

  for r in select id from public.tentative
            where eleve_id = auth.uid() and cours_id = p_cours and type = 'evaluation_cours' and statut = 'en_cours' loop
    if not prive.cloturer_si_expiree(r.id) then
      return r.id;
    end if;
  end loop;

  select count(*), count(*) filter (where pc.valide) into v_nb_chapitres, v_nb_valides
    from public.chapitre c
    left join public.progression_chapitre pc on pc.chapitre_id = c.id and pc.eleve_id = auth.uid()
   where c.cours_id = p_cours and c.publie;
  if v_nb_chapitres = 0 or v_nb_valides < v_nb_chapitres then
    raise exception 'evaluation_verrouillee';
  end if;

  select count(*), max(fin) into v_essais, v_derniere_fin from public.tentative
   where eleve_id = auth.uid() and cours_id = p_cours and type = 'evaluation_cours';
  if v_essais >= 3 then
    raise exception 'essais_epuises';
  end if;
  if v_derniere_fin > now() - interval '24 hours' then
    raise exception 'delai_attente';
  end if;

  select count(*) into v_dispo
    from public.question q join public.chapitre c on c.id = q.chapitre_id
   where c.cours_id = p_cours and c.publie and q.statut = 'valide';
  if v_dispo = 0 then
    raise exception 'quiz_indisponible';
  end if;

  insert into public.tentative (eleve_id, type, cours_id, nb_questions, date_limite)
    values (auth.uid(), 'evaluation_cours', p_cours, least(40, v_dispo), now() + interval '60 minutes')
    returning id into v_id;

  -- Le rang dans chaque chapitre, tiré au hasard, alterne les chapitres : la répartition est équilibrée
  -- et un chapitre trop court laisse automatiquement sa place aux autres.
  insert into public.tentative_question (tentative_id, ordre, question_id, permutation)
    select v_id, row_number() over (order by s.rang, s.alea), s.id, prive.melanger(jsonb_array_length(s.propositions))
      from (
        select q.id, q.propositions, random() as alea,
               row_number() over (partition by q.chapitre_id order by random()) as rang
          from public.question q join public.chapitre c on c.id = q.chapitre_id
         where c.cours_id = p_cours and c.publie and q.statut = 'valide'
         order by rang, alea
         limit 40
      ) s;
  return v_id;
end $$;
```

```sql
-- Données du tableau de bord : lues avec les droits de l'élève (RLS).

create function public.points_faibles(p_limite int default 5)
returns table (chapitre_id uuid, cours_slug text, chapitre_slug text, libelle text, taux_erreur int, reponses int)
language sql stable set search_path = '' as $$
  select c.id, co.slug, c.slug, coalesce(n.nom, c.titre),
         round(100.0 * sum(h.ratee) / sum(h.vue))::int, sum(h.vue)::int
    from public.historique_question h
    join public.question q on q.id = h.question_id
    join public.chapitre c on c.id = q.chapitre_id
    join public.cours co on co.id = c.cours_id
    left join public.notion n on n.id = q.notion_id
   where h.eleve_id = (select auth.uid())
   group by c.id, co.slug, c.slug, c.titre, n.id, n.nom
  having sum(h.vue) >= 3 and sum(h.ratee) > 0
   order by sum(h.ratee)::numeric / sum(h.vue) desc, sum(h.vue) desc
   limit p_limite
$$;

create function public.serie_jours() returns int
language sql stable set search_path = '' as $$
  with jours as (
    select distinct (fin at time zone 'Europe/Paris')::date as j
      from public.tentative
     where eleve_id = (select auth.uid()) and statut <> 'en_cours' and fin is not null
  ), groupes as (
    select j, j - (row_number() over (order by j))::int as g from jours
  ), series as (
    select max(j) as dernier, count(*)::int as longueur from groupes group by g
  )
  select coalesce((select longueur from series
                    where dernier >= (now() at time zone 'Europe/Paris')::date - 1
                    order by dernier desc limit 1), 0)
$$;

revoke execute on function public.points_faibles(int), public.serie_jours() from public, anon;
grant execute on function public.points_faibles(int), public.serie_jours() to authenticated;
```

```ts
// Règles de la spec. La base les applique ; ces constantes servent à l'affichage.
export const SEUIL_REUSSITE = 75;
export const LONGUEURS_QUIZ = [15, 20, 30] as const;
export const MIN_QUESTIONS_QUIZ = 15;
export const EVALUATION = { nbQuestions: 40, dureeMinutes: 60, essais: 3, delaiHeures: 24 } as const;

export type StatutTentative = 'en_cours' | 'terminee' | 'expiree';
export type EtatEvaluation =
  | { etat: 'verrouillee'; chapitresRestants: number }
  | { etat: 'en_cours'; tentativeId: string }
  | { etat: 'disponible'; essaisRestants: number }
  | { etat: 'attente'; disponibleLe: Date; essaisRestants: number }
  | { etat: 'epuisee' };

type Entree = {
  nbChapitres: number;
  nbValides: number;
  essais: { id: string; statut: StatutTentative; fin: string | null }[];
  maintenant: Date;
};

export function etatEvaluation({ nbChapitres, nbValides, essais, maintenant }: Entree): EtatEvaluation {
  const enCours = essais.find((e) => e.statut === 'en_cours');
  if (enCours) return { etat: 'en_cours', tentativeId: enCours.id };
  if (nbChapitres === 0 || nbValides < nbChapitres) {
    return { etat: 'verrouillee', chapitresRestants: nbChapitres - nbValides };
  }
  const essaisRestants = EVALUATION.essais - essais.length;
  if (essaisRestants <= 0) return { etat: 'epuisee' };
  const fins = essais.map((e) => (e.fin ? new Date(e.fin).getTime() : 0));
  const derniere = fins.length > 0 ? Math.max(...fins) : 0;
  const disponibleLe = new Date(derniere + EVALUATION.delaiHeures * 3600 * 1000);
  if (derniere > 0 && disponibleLe > maintenant) return { etat: 'attente', disponibleLe, essaisRestants };
  return { etat: 'disponible', essaisRestants };
}
```

```ts
export type TypeQuestion = 'qcm_unique' | 'qcm_multiple' | 'vrai_faux' | 'reponse_courte';
/** Réponse dans l'ordre d'affichage : indices des propositions, [vrai|faux] ou [texte]. */
export type ReponseAffichee = number[] | boolean[] | string[];

export function basculerChoix(actuelle: number[] | null, index: number): number[] | null {
  const choix = new Set(actuelle ?? []);
  if (choix.has(index)) choix.delete(index); else choix.add(index);
  return choix.size === 0 ? null : [...choix].sort((a, b) => a - b);
}

export function estRepondue(reponse: ReponseAffichee | null | undefined): boolean {
  if (!Array.isArray(reponse) || reponse.length === 0) return false;
  return typeof reponse[0] !== 'string' || reponse[0].trim() !== '';
}

export function texteReponse(type: TypeQuestion, propositions: string[], valeur: ReponseAffichee | null): string {
  if (!estRepondue(valeur)) return 'Pas de réponse';
  switch (type) {
    case 'qcm_unique':
    case 'qcm_multiple':
      return (valeur as number[]).map((i) => propositions[i]).join(' ; ');
    case 'vrai_faux':
      return (valeur as boolean[])[0] ? 'Vrai' : 'Faux';
    case 'reponse_courte':
      return (valeur as string[])[0];
  }
}

export function formaterNote(note: number): string {
  const arrondi = Math.round(note * 10) / 10;
  return `${String(arrondi).replace('.', ',')} %`;
}
```

```tsx
        finAppelee.current = true;
        rappel.current();
      }
    };
    tic();
    const id = setInterval(tic, 1000);
    return () => clearInterval(id);
  }, [dateLimite, serveurMaintenant]);

  if (restant === null) return <span className="compte-a-rebours">⏱ …</span>;
  const minutes = Math.max(0, Math.ceil(restant / 60000));
  return (
    <span className={`compte-a-rebours${restant <= 5 * 60000 ? ' bientot' : ''}`} role="timer"
      aria-label={`Temps restant : environ ${minutes} minute${minutes > 1 ? 's' : ''}`}>
      ⏱ {formaterDuree(restant)}
    </span>
```

```tsx
'use client';

import { useRef, useState, useTransition } from 'react';
import { useRouter } from 'next/navigation';
import { enregistrerReponse, terminerTentative } from '@/app/(app)/tentative/actions';
import { estRepondue, type ReponseAffichee } from '@/lib/quiz/reponse';
import type { QuestionAffichee } from '@/lib/quiz/requetes';
import { BarreProgression } from './BarreProgression';
import { ChampReponse } from './ChampReponse';
import { CompteARebours } from './CompteARebours';

type Props = { tentativeId: string; questions: QuestionAffichee[]; dateLimite: string | null; serveurMaintenant: number };
type Sauvegarde = 'ok' | 'en_cours' | 'erreur';
const LIBELLES: Record<Sauvegarde, string> = { ok: 'Réponses enregistrées', en_cours: 'Enregistrement…', erreur: 'Non enregistré : vérifie ta connexion' };

export function LecteurTentative({ tentativeId, questions, dateLimite, serveurMaintenant }: Props) {
  const router = useRouter();
  const [index, setIndex] = useState(() => Math.max(0, questions.findIndex((q) => !estRepondue(q.reponse))));
  const [reponses, setReponses] = useState<Record<string, ReponseAffichee | null>>(
    () => Object.fromEntries(questions.map((q) => [q.question_id, q.reponse])),
  );
  const [sauvegarde, setSauvegarde] = useState<Sauvegarde>('ok');
  const [enFin, demarrerFin] = useTransition();
  // Enregistrements en vol : la fin du quiz les attend pour ne perdre aucune réponse.
  const enVol = useRef(new Set<Promise<void>>());
  const question = questions[index];
  const nbRepondues = questions.filter((q) => estRepondue(reponses[q.question_id])).length;

  function sauver(questionId: string, reponse: ReponseAffichee | null): Promise<void> {
    const promesse = envoyer(questionId, reponse).finally(() => enVol.current.delete(promesse));
    enVol.current.add(promesse);
    return promesse;
  }

  async function envoyer(questionId: string, reponse: ReponseAffichee | null) {
    setSauvegarde('en_cours');
    for (let essai = 0; essai < 3; essai++) {
      const r = await enregistrerReponse(tentativeId, questionId, reponse);
      if ('statut' in r) {
        if (r.statut !== 'ok') router.replace(`/tentative/${tentativeId}/resultat`);
        else setSauvegarde('ok');
        return;
      }
      await new Promise((ok) => setTimeout(ok, 800 * (essai + 1)));
    }
    setSauvegarde('erreur');
  }

  function changer(reponse: ReponseAffichee | null, enregistrerTout: boolean) {
    setReponses((r) => ({ ...r, [question.question_id]: reponse }));
    if (enregistrerTout) void sauver(question.question_id, reponse);
  }

  async function enregistrerTexteEnCours() {
    if (question.type === 'reponse_courte') await sauver(question.question_id, reponses[question.question_id] ?? null);
  }

  function aller(cible: number) {
    void enregistrerTexteEnCours();
    setIndex(cible);
  }

  function terminer(demanderConfirmation: boolean) {
    const manquantes = questions.length - nbRepondues;
    if (demanderConfirmation && manquantes > 0
      && !window.confirm(`Il te reste ${manquantes} question${manquantes > 1 ? 's' : ''} sans réponse. Terminer quand même ?`)) return;
    demarrerFin(async () => {
      await enregistrerTexteEnCours();
      await Promise.all([...enVol.current]);
      await terminerTentative(tentativeId);
    });
  }

  const derniere = index === questions.length - 1;
  return (
    <div className="lecteur">
      <div className="lecteur-barre">
        <span className="lecteur-position">Question {index + 1} / {questions.length}</span>
        {dateLimite && <CompteARebours dateLimite={dateLimite} serveurMaintenant={serveurMaintenant} onFin={() => terminer(false)} />}
        <span className={`sauvegarde sauvegarde-${sauvegarde}`} role="status">{LIBELLES[sauvegarde]}</span>
      </div>
      <BarreProgression valeur={nbRepondues} max={questions.length} libelle="Questions répondues" />

      <fieldset className="carte question" key={question.question_id}>
        <legend className="question-enonce">{question.enonce}</legend>
        <ChampReponse questionId={question.question_id} type={question.type} propositions={question.propositions}
          reponse={reponses[question.question_id] ?? null} onChange={changer} />
      </fieldset>

      <div className="lecteur-navigation">
        <button type="button" className="bouton bouton-secondaire" disabled={index === 0 || enFin} onClick={() => aller(index - 1)}>← Précédente</button>
        {derniere
          ? <button type="button" className="bouton bouton-principal" disabled={enFin} onClick={() => terminer(true)}>{enFin ? 'Correction…' : 'Terminer'}</button>
          : <button type="button" className="bouton bouton-principal" disabled={enFin} onClick={() => aller(index + 1)}>Suivante →</button>}
      </div>

      <nav aria-label="Aller à une question">
        <ol className="pastilles-questions">
          {questions.map((q, i) => {
            const repondue = estRepondue(reponses[q.question_id]);
            return (
              <li key={q.question_id}>
                <button type="button" className={repondue ? 'repondue' : undefined} aria-current={i === index ? 'step' : undefined}
                  aria-label={`Question ${i + 1}${repondue ? ', répondue' : ''}`} onClick={() => aller(i)}>{i + 1}</button>
              </li>
            );
          })}
        </ol>
      </nav>
      {!derniere && <button type="button" className="bouton bouton-secondaire" disabled={enFin} onClick={() => terminer(true)}>Terminer maintenant</button>}
    </div>
  );
}
```

```tsx
              <CarteCours key={c.id} {...c} nbValides={tdb?.validesParCours.get(c.id) ?? 0} />
            ))}</div>}
      </section>

      <section aria-labelledby="titre-examens">
        <h2 id="titre-examens">Mes notes d’examen</h2>
        {!tdb || tdb.examens.length === 0 ? (
          <p className="vide">Pas encore d’évaluation passée. Valide les chapitres d’un cours pour débloquer la sienne.</p>
        ) : (
          <ul className="liste-tdb">
            {tdb.examens.map((e) => (
              <li key={e.cours?.slug} className="carte ligne-tdb">
                <Link href={`/cours/${e.cours?.slug}/evaluation`}>{e.cours?.titre}</Link>
                <strong className={e.valide ? 'note-reussie' : 'note-ratee'}>{formaterNote(Number(e.meilleure_note ?? 0))}</strong>
                <span>{e.valide ? 'Réussie' : 'À repasser'} · {e.essais} essai{e.essais > 1 ? 's' : ''}</span>
              </li>
            ))}
          </ul>
        )}
      </section>

      <section aria-labelledby="titre-quiz">
        <h2 id="titre-quiz">Mes derniers quiz</h2>
        {!tdb || tdb.derniers.length === 0 ? (
          <p className="vide">Lance ton premier quiz depuis un chapitre !</p>
        ) : (
          <ul className="liste-tdb">
            {tdb.derniers.map((t) => (
              <li key={t.id} className="carte ligne-tdb">
                <Link href={`/tentative/${t.id}/resultat`}>
                  {t.type === 'evaluation_cours' ? `Évaluation · ${t.cours?.titre}` : t.chapitre?.titre ?? t.cours?.titre}
                </Link>
                <strong className={t.reussie ? 'note-reussie' : 'note-ratee'}>{formaterNote(Number(t.note ?? 0))}</strong>
                <span>{t.fin ? jour.format(new Date(t.fin)) : ''}</span>
              </li>
            ))}
          </ul>
        )}
      </section>

      {tdb && tdb.pointsFaibles.length > 0 && (
        <section aria-labelledby="titre-faibles">
          <h2 id="titre-faibles">À retravailler</h2>
          <ul className="liste-tdb">
            {tdb.pointsFaibles.map((p) => (
              <li key={`${p.chapitre_id}-${p.libelle}`} className="carte ligne-tdb ligne-faible">
                <Link href={`/cours/${p.cours_slug}/${p.chapitre_slug}`}>{p.libelle}</Link>
                <span>{p.taux_erreur} % d’erreurs sur {p.reponses} réponses</span>
                <FormulaireQuiz chapitreId={p.chapitre_id} longueurs={[15]} revision libelle="Réviser" />
              </li>
            ))}
          </ul>
        </section>
      )}
    </div>
  );
}
```

```ts
import { createClient } from '@supabase/supabase-js';
import type { Database } from '../src/lib/supabase/types';

process.loadEnvFile('.env.local');
export const db = createClient<Database>(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.SUPABASE_SERVICE_ROLE_KEY!, {
  auth: { persistSession: false },
});

/** Bonnes réponses d'une tentative dans l'ordre d'affichage : réservé aux tests (clé service_role). */
export async function bonnesReponsesAffichees(tentativeId: string): Promise<number[][]> {
  const { data, error } = await db.from('tentative_question')
    .select('ordre, permutation, question_corrige:question_id(question_corrige(bonnes_reponses))')
    .eq('tentative_id', tentativeId).order('ordre');
  if (error || !data) throw error ?? new Error('tentative introuvable');
  return data.map((ligne) => {
    const corrige = (ligne.question_corrige as unknown as { question_corrige: { bonnes_reponses: number[] } }).question_corrige;
    return corrige.bonnes_reponses.map((origine) => ligne.permutation.indexOf(origine));
  });
}

export async function validerTousLesChapitres(email: string, coursSlug: string) {
  const { data: profil } = await db.from('profil').select('id').eq('email', email).single();
  const { data: cours } = await db.from('cours').select('chapitre(id)').eq('slug', coursSlug).single();
  if (!profil || !cours) throw new Error('profil ou cours introuvable');
  const lignes = cours.chapitre.map((c) => ({ eleve_id: profil.id, chapitre_id: c.id, meilleure_note: 100, valide: true }));
  const { error } = await db.from('progression_chapitre').upsert(lignes);
  if (error) throw error;
}
```
